Pubblica online

Le modifiche vengono salvate nel file assets/listino.js del sito su GitHub. Il sito si aggiorna in 1–2 minuti. Serve un token personale GitHub con permesso di scrittura limitato al solo repository del sito (istruzioni sotto). Il token resta solo in questo browser.

Come creare il token (una sola volta)

  1. Accedi a GitHub con l'account del sito, poi apri Settings → Developer settings → Personal access tokens → Fine-grained tokens e premi Generate new token.
  2. Nome: «Gestione listino»; scadenza: a scelta (ad esempio 1 anno).
  3. Repository access: Only select repositories → astra-formazione.
  4. Permissions → Repository permissions → Contents: Read and write. Nessun altro permesso.
  5. Premi Generate token, copia il codice e incollalo qui sopra. Non condividerlo con nessuno; se lo perdi, revocalo e creane un altro.

In alternativa puoi premere «Scarica listino.js» e caricare il file su GitHub nella cartella assets del repository (pulsante Add file → Upload files).
